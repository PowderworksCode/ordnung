Each one is a focused recipe for a single job, assuming you already know the
basics from [getting started](/getting-started).

- [Check an existing repository](/how-to-guides/check-a-repository) — Check a repository locally, run the full GitHub-backed audit, and hand findings to another tool.
- [Use the GitHub Action](/how-to-guides/use-github-action) — Run repository checks or fleet remediation through the packaged Ordnung Action.
- [Generate agent instructions](/how-to-guides/generate-agent-instructions) — Render the checks in force as rules coding agents read, injected into AGENTS.md or CLAUDE.md.
- [Set up a fleet](/how-to-guides/set-up-a-fleet) — Create a fleet configuration naming member repositories and the policy they share.
- [Synchronize a fleet member](/how-to-guides/sync-a-fleet-member) — Preview and apply centrally managed configuration to one local repository.
